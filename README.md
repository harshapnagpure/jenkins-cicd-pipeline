# Jenkins CI/CD Pipeline Automation Using Groovy

## Project Overview
This project demonstrates a basic CI/CD pipeline using Jenkins Declarative Pipeline and Groovy scripting.

## Tools & Technologies
- Jenkins
- Jenkinsfile
- Groovy
- CI/CD
- Git
- GitHub

## Pipeline Stages
1. Checkout - Simulates checking out the application source code.
2. Build - Simulates the application build process.
3. Test - Simulates application testing.
4. Deploy - Simulates deployment based on the selected environment.

## What I Practiced
- Created a Jenkins Declarative Pipeline using a Jenkinsfile.
- Used Groovy variables, conditional statements, lists, and loops.
- Configured build parameters for Dev, QA, and Prod environments.
- Executed the pipeline and checked the results in Jenkins Console Output and Stage View.

## Note
Build, test, and deployment steps are simulated for learning purposes. No actual application deployment is performed.
